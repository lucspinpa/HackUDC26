# HackUDC26 🧙‍♂️

## README ✨ 📁
Datei es una aplicación web que permite subir archivos fácilmente, almacenarlos de forma organizada, buscar archivos mediante conceptos clave y obtener resultados rápidos y relevantes. Nuestro objetivo es facilitar la gestión y recuperación de documentos de forma intuitiva y eficiente.

### Características principales: 🗂️
* Subida de múltiples archivos
* Soporte para diferentes formatos (PDF, DOCX, TXT, etc.)
* Indexación automática del contenido
* Búsqueda por elementos clave
* Interfaz simple y amigable
* Resultados ordenados por relevancia

### ¿Cómo funciona? ⚙️
1. El usuario sube uno o varios archivos.
2. El sistema extrae el contenido del archivo.
3. Se indexa el texto para permitir búsquedas rápidas.
4. El usuario introduce un concepto clave.
5. El sistema devuelve los archivos más relevantes que se correspondan con la búsqueda.
6. Y también se permite filtrar por formato de documento.

### Tecnologías utilizadas 🖨️
- Frontend: React
- Backend: Node.js
- Base de datos: JSON
- Motor de búsqueda: búsqueda personalizada con IA (LLM Ollama) 🦙
- Almacenamiento: servidor externo
